Глава II • § 4, п. 36

П. 36. Свойства действий с рациональными числами

Все свойства из начальной школы работают — теперь и с минусами

Привет! Помнишь переместительное свойство из 5 класса? С рациональными числами оно работает точно так же: \(−2,4 + 5,7 = 5,7 + (−2,4)\). Сегодня убедимся, что все свойства действий действуют и с минусами — и научимся считать ими длинные суммы.

Свойства действий

Для рациональных чисел a, b, c верны: \(a + b = b + a\) (переместительное); \(a + (b + c) = (a + b) + c\) (сочетательное); \(a \cdot b = b \cdot a\); \(a\cdot(b\cdot c) = (a\cdot b)\cdot c\); \((a + b)\cdot c = a\cdot c + b\cdot c\) (распределительное).

Особые случаи: \(a + 0 = a\); \(a + (−a) = 0\); \(a \cdot 1 = a\); \(a \cdot 0 = 0\); произведение равно нулю, только если хотя бы один множитель равен нулю.

📌 Задача. Проверим переместительное свойство при m = −2 1/4, n = −4 1/8 (упр. 4.365).

  1. \(m + n = −2\frac{1}{4} + (−4\frac{1}{8}) = −6\frac{3}{8}\)
  2. \(n + m = −4\frac{1}{8} + (−2\frac{1}{4}) = −6\frac{3}{8}\)
  3. Оба значения равны — свойство выполняется ✓

✅ Ответ: \(−6\frac{3}{8} = −6\frac{3}{8}\)

Свойство противоположных чисел

Слагаемые-противоположные взаимно уничтожаются: \(256 − 121 − 236 − 256 + 121 = −236\), ведь \(256 + (−256) = 0\) и \(−121 + 121 = 0\). Это свойство экономит половину вычислений.

📌 Задача. Вычислим, используя свойство противоположных чисел: −4,42 + 4,3 − 4,8 + 4,42 − 4,3 (упр. 4.368).

  1. Группируем: \((−4,42 + 4,42) + (4,3 − 4,3) − 4,8\)
  2. Обе пары дают нуль
  3. Остаётся \(−4,8\) ✓

✅ Ответ: \(−4,8\)

Группировка в длинных суммах

В алгебраической сумме складывай отдельно плюсы и отдельно минусы, либо собирай «круглые» пары: \(−23 + 72 + 37 − 21 − 36 + 51 = (72 + 37 + 51) + (−23 − 21 − 36) = 160 − 80 = 80\).

💡 Методическая подсказка № 36: Ищи нулевые пары и круглые суммы

Устройство. Свойства — «инструменты перестановки»: меняй порядок так, чтобы числа дружили.

Правило-шаги. 1) Найди противоположные пары (a и −a) — они дают 0. 2) Найди пары с круглой суммой (…,9 + …,1). 3) Остальное — плюсы отдельно, минусы отдельно.

Проверь на контрасте: \(−1,7 + 5 + 1,7 = 5\) ✅ (пара сгорела). А считать всё подряд слева направо 🚫 — дольше и опаснее.

Мостик: в заданиях 3 и 6 сначала пометь пары-«убийцы», потом считай остаток.

🟢 Уровень 1№ 4.365 (а)

Запишите переместительное свойство сложения и проверьте его при \(m = 0,9, n = 2,4\).

  1. Свойство: \(m + n = n + m\)
  2. \(0,9 + 2,4 = 3,3\); \(2,4 + 0,9 = 3,3\)
  3. \(3,3 = 3,3\) — свойство выполняется ✓

Ответ: \(0,9 + 2,4 = 2,4 + 0,9 = 3,3\)

🟢 Уровень 1№ 4.369 (а, б)

Упростите выражение: а) \(a + 9 − a − 13\); б) \(−n − m + 29 + m − 29\).

  1. а) \((a − a) + (9 − 13) = 0 − 4 = −4\)
  2. б) \((−m + m) + (29 − 29) − n = −n\)
  3. Противоположные слагаемые взаимно уничтожились ✓

Ответ: а) −4; б) −n

🔵 Уровень 2№ 4.368 (а, б)

Вычислите, используя свойство противоположных чисел: а) \(256 − 121 − 236 − 256 + 121\); б) \(−4,42 + 4,3 − 4,8 + 4,42 − 4,3\).

  1. а) \((256 − 256) + (−121 + 121) − 236 = −236\)
  2. б) \((−4,42 + 4,42) + (4,3 − 4,3) − 4,8 = −4,8\)
  3. Нулевые пары упростили обе суммы ✓

Ответ: а) −236; б) −4,8

🔵 Уровень 2№ 4.367 (а, б)

Вычислите значение алгебраической суммы: а) \(−23 + 72 + 37 − 21 − 36 + 51\); б) \(3,26 − 4,34 − 4,01 + 6,28 + 1,36 − 5,55\).

  1. а) Плюсы: 72 + 37 + 51 = 160; минусы: −23 − 21 − 36 = −80; \(160 − 80 = 80\)
  2. б) Плюсы: 3,26 + 6,28 + 1,36 = 10,9; минусы: −4,34 − 4,01 − 5,55 = −13,9; \(10,9 − 13,9 = −3\)
  3. Проверка: 160 = 2 · 80 — считалось без остатка ✓

Ответ: а) 80; б) −3

🟣 Уровень 3№ 4.367 (в, г)

Вычислите значение алгебраической суммы: в) \(3\frac{1}{3} + 5\frac{1}{6} − 2\frac{5}{8} − 7\frac{1}{4} − 1\frac{1}{8}\); г) \(0,7 − \frac{7}{12} − \frac{1}{6} + 0,5 − \frac{1}{4} + 0,3\).

  1. в) Целые: 3 + 5 − 2 − 7 − 1 = −2; дроби: 2/6 + 1/6 − 5/8 − 2/8 − 1/8 = 1/2 − 1 = −1/2; итог \(−2\frac{1}{2}\)
  2. г) Десятичные: 0,7 + 0,5 + 0,3 = 1,5; дроби: −(7/12 + 2/12 + 3/12) = −1; итог \(1,5 − 1 = 0,5\)
  3. Проверка: в обоих пунктах дробные части сложены по НОЗ ✓

Ответ: в) −21/2; г) 0,5

🟣 Уровень 3№ 4.368 (г)

Вычислите, используя свойства: \(0,2 + 3\frac{2}{5} − 6,6 − 3,4 − \frac{2}{5} + 6,6\).

  1. Противоположная пара: \(−6,6 + 6,6 = 0\)
  2. Дробная пара: \(3\frac{2}{5} − \frac{2}{5} = 3\)
  3. Остаётся: \(0,2 + 3 − 3,4 = −0,2\) ✓

Ответ: \(−0,2\)

🎓 Главное из урока

  • Все свойства действий верны для рациональных чисел.
  • Переместительное и сочетательное свойства позволяют менять порядок и группировку.
  • Распределительное свойство: (a + b)·c = a·c + b·c.
  • a + (−a) = 0 — противоположные слагаемые взаимно уничтожаются.
  • a · 1 = a; a · 0 = 0.
  • Произведение равно нулю, только если хотя бы один множитель — нуль.
  • Плюсы и минусы в длинной сумме удобно собирать отдельно.
