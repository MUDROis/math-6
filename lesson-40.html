Глава II • § 5, п. 40

П. 40. Решение уравнений

Переносим слагаемые через «равно» — и знак меняется

Привет! Уравнение \(7x = 3x + 4\) похоже на весы: с обеих чашек можно снять по три пакета — равновесие сохранится. Так рождается главное правило урока: слагаемое можно перенести из одной части уравнения в другую, изменив его знак. Сегодня научимся решать любые линейные уравнения и задачи с их помощью.

Свойства уравнений

1. Если обе части уравнения умножить или разделить на одно и то же число, не равное нулю, корни не изменятся. 2. Слагаемое можно перенести из одной части уравнения в другую, изменив его знак на противоположный.

Пример: \(3x + 4 = 22\) → переносим 4: \(3x = 22 − 4 = 18\) → \(x = 6\). Проверка: \(3 \cdot 6 + 4 = 22\) ✓.

📌 Задача. Решим уравнение 7x = 3x + 4 (пример из учебника).

  1. Переносим 3x влево со сменой знака: \(7x − 3x = 4\)
  2. Приводим подобные: \(4x = 4\)
  3. \(x = 1\). Проверка: \(7 \cdot 1 = 3 \cdot 1 + 4\) ✓

✅ Ответ: \(x = 1\)

Алгоритм решения линейного уравнения

Шаги: 1) раскрой скобки (если есть); 2) перенеси слагаемые с x влево, числа вправо (со сменой знаков); 3) приведи подобные слагаемые; 4) раздели обе части на коэффициент при x.

Если при x остался ненулевой коэффициент — корень один. Если получилось \(0x = b\) при b ≠ 0 — корней нет; при b = 0 — любое число является корнем.

📌 Задача. Решим уравнение −50 · (−9x + 3) = −15000 (упр. 5.99).

  1. Разделим обе части на −50: \(−9x + 3 = 300\)
  2. Переносим 3: \(−9x = 297\)
  3. \(x = 297 : (−9) = −33\). Проверка: \(−50 \cdot (297 + 3) = −50 \cdot 300 = −15000\) ✓

✅ Ответ: \(x = −33\)

Задачи решаются уравнением

Схема: обозначь неизвестное буквой → составь уравнение по условию → реши → истолкуй ответ и проверь. Например, про книги на полках: пусть на второй полке x книг, тогда на первой 2x, на третьей 2x − 5; уравнение \(x + 2x + 2x − 5 = 75\).

💡 Методическая подсказка № 40: Перенёс слагаемое — поменяй знак

Устройство. Уравнение — весы: любые одинаковые действия с обеими чашами сохраняют равенство; «перенос» — это вычитание слагаемого из обеих частей.

Правило-шаги. 1) Скобки — раскрыть. 2) x — налево, числа — направо, каждый переход — со сменой знака. 3) Подобные — привести. 4) Разделить на коэффициент. 5) Проверка подстановкой — обязательна.

Проверь на контрасте: из \(7x − 21 = 6x + 3\) перенос даёт \(7x − 6x = 3 + 21\) ✅. А оставить \(= 3 − 21\) 🚫 — знак при переносе не сменился.

Мостик: в заданиях 5 и 6 сначала составь уравнение по условию — дальше алгоритм из четырёх шагов.

Уравнение на весах

✍️ Проверь себя

Шесть заданий по нарастающей: два на прямой счёт (Уровень 1), два на комбинацию правил (Уровень 2) и два на смекалку (Уровень 3). Сначала реши сам — потом нажми «Проверить» и сверь каждый шаг.

🟢 Уровень 1№ 5.97 (а, д)

Решите уравнение: а) \(7x − 21 = 6x + 3\); д) \(8 + 27a = 10 + 26a\).

  1. а) \(7x − 6x = 3 + 21\) → \(x = 24\)
  2. д) \(27a − 26a = 10 − 8\) → \(a = 2\)
  3. Проверка: \(7\cdot24 − 21 = 147 = 6\cdot24 + 3\) ✓; \(8 + 54 = 62 = 10 + 52\) ✓

Ответ: а) x = 24; д) a = 2

🟢 Уровень 1№ 5.97 (е, з)

Решите уравнение: е) \(13 − 7x = 14 − 8x\); з) \(2 − 5x = 4 − 6x\).

  1. е) \(−7x + 8x = 14 − 13\) → \(x = 1\)
  2. з) \(−5x + 6x = 4 − 2\) → \(x = 2\)
  3. Проверка: \(13 − 7 = 6 = 14 − 8\) ✓; \(2 − 10 = −8 = 4 − 12\) ✓

Ответ: е) x = 1; з) x = 2

🔵 Уровень 2№ 5.100 (а, и)

Решите уравнение: а) \(0,7x + 4 = 0,3x\); и) \(17x + 34 = 0\).

  1. а) \(0,7x − 0,3x = −4\) → \(0,4x = −4\) → \(x = −10\)
  2. и) \(17x = −34\) → \(x = −2\)
  3. Проверка: \(0,7\cdot(−10) + 4 = −3 = 0,3\cdot(−10)\) ✓; \(17\cdot(−2) + 34 = 0\) ✓

Ответ: а) x = −10; и) x = −2

🔵 Уровень 2№ 5.99 (б, в)

Найдите корень уравнения и выполните проверку: б) \((−30x − 60) \cdot 2 = 120\); в) \(−4 \cdot (3 − 21x) = −12\).

  1. б) Делим на 2: \(−30x − 60 = 60\) → \(−30x = 120\) → \(x = −4\)
  2. в) Делим на −4: \(3 − 21x = 3\) → \(−21x = 0\) → \(x = 0\)
  3. Проверка: \((120 − 60)\cdot2 = 120\) ✓; \(−4 \cdot 3 = −12\) ✓

Ответ: б) x = −4; в) x = 0

🟣 Уровень 3№ 5.91

На трёх полках 75 книг. На первой полке книг в 2 раза больше, чем на второй, а на третьей на 5 книг меньше, чем на первой. Сколько книг на каждой полке?

  1. Пусть на второй полке x книг; тогда первая — 2x, третья — 2x − 5
  2. \(x + 2x + 2x − 5 = 75\) → \(5x = 80\) → \(x = 16\)
  3. Полки: 32, 16 и 27 книг. Проверка: \(32 + 16 + 27 = 75\) ✓

Ответ: 32, 16 и 27 книг

🟣 Уровень 3№ 5.90

Цена килограмма яблок на 20 р. ниже цены килограмма груш. Купили 3 кг груш и 5 кг яблок, заплатив 660 р. По какой цене покупали фрукты?

  1. Пусть груши стоят x р./кг, тогда яблоки — x − 20 р./кг
  2. \(3x + 5(x − 20) = 660\) → \(3x + 5x − 100 = 660\)
  3. \(8x = 760\) → \(x = 95\): груши — 95 р., яблоки — 75 р.
  4. Проверка: \(3\cdot95 + 5\cdot75 = 285 + 375 = 660\) ✓

Ответ: груши — 95 р./кг, яблоки — 75 р./кг

🎓 Главное из урока

  • Корень уравнения не меняется при умножении/делении обеих частей на число ≠ 0.
  • Слагаемое переносится через «равно» со сменой знака.
  • Алгоритм: скобки → перенос → подобные → деление на коэффициент.
  • Проверка корня подстановкой обязательна.
  • 0x = b: при b ≠ 0 корней нет, при b = 0 — любой x.
  • Задачи решают уравнением: обозначь неизвестное, составь уравнение, реши, истолкуй.
  • Ответ задачи проверяют по условию, а не только подстановкой в уравнение.
