Глава II • § 4, п. 34

П. 34. Действие деления

Знаки делятся по тем же правилам: минус на минус — плюс

Привет! Разделить −18 на −9 — значит найти число a, что −9 · a = −18. Значит a = 2: минус на минус дал плюс. Правила знаков в делении — те же, что в умножении. Сегодня тренируем частные и учимся ловить чужие ошибки.

Правила знаков при делении

При делении чисел с разными знаками частное отрицательно: раздели модуль делимого на модуль делителя и поставь «−». При делении отрицательных чисел частное положительно: раздели модули.

Например: −24 : 2 = −12; −8,4 : (−4) = 2,1; 3,8 : (−1) = −3,8 (а не 3,8 — вот типичная ошибка!).

📌 Задача. Выполним деление −34 : 17 и −48 : (−16) (упр. 4.306).

  1. −34 : 17 = −(34 : 17) = −2
  2. −48 : (−16) = +(48 : 16) = 3
  3. Проверка умножением: −2 · 17 = −34; 3 · (−16) = −48 ✓

✅ Ответ: −2 и 3

Частное с дробями

Делим на дробь — умножаем на перевёрнутую (правило урока 15), а знаки определяем как всегда: −7/9 : 2/3 = −7/9 · 3/2 = −7/6 = −1 1/6; −3/13 : (−9/26) = 3/13 · 26/9 = 2/3.

📌 Задача. Найдём частное −4/9 : 2/3 (по образцу упр. 4.309).

  1. Переворачиваем делитель: −4/9 · 3/2
  2. Сокращаем: −(4 · 3)/(9 · 2) = −2/3
  3. Знак: минус (разные знаки). Проверка: −2/3 · 2/3 = −4/9 ✓

✅ Ответ: −2/3

Порядок действий

В выражениях порядок прежний: сначала умножение и деление, потом сложение и вычитание. Например: −6·(−5) − (−40):8 = 30 + 5 = 35.

💡 Методическая подсказка № 34: Проверяй частное умножением

Устройство. Деление — «обратное умножение»: частное · делитель = делимое. Это встроенная проверка.

Правило-шаги. 1) Раздели модули. 2) Определи знак по числу минусов. 3) Проверь: частное × делитель = делимое.

Проверь на контрасте: 100 : (−2,5) = −40 ✅. А написать −4 🚫 — модуль поделили «на глаз». Проверка умножением мгновенно ловит ошибку: −4·(−2,5) = 10 ≠ 100.

Мостик: в задании 1 именно проверка умножением выявит неверные равенства.

Ловим ошибку проверкой

✍️ Проверь себя

Шесть заданий по нарастающей: два на прямой счёт (Уровень 1), два на комбинацию правил (Уровень 2) и два на смекалку (Уровень 3). Сначала реши сам — потом нажми «Проверить» и сверь каждый шаг.

🟢 Уровень 1№ 4.305

Верно ли выполнено деление: а) −24 : 2 = −12; б) 100 : (−2,5) = −4; в) 3,8 : (−1) = 3,8; г) −8,4 : (−4) = 2,1?

  1. а) −24 : 2 = −12 — верно ✓
  2. б) 100 : (−2,5) = −40, а не −4 — неверно
  3. в) 3,8 : (−1) = −3,8, а не 3,8 — неверно (потерян минус)
  4. г) −8,4 : (−4) = 2,1 — верно ✓

Ответ: верно: а), г); неверно: б), в)

🟢 Уровень 1№ 4.306 (а, г)

Выполните деление: а) −34 : 17; г) −25 : (−5).

  1. а) −34 : 17 = −2
  2. г) −25 : (−5) = 5
  3. Проверка: −2 · 17 = −34; 5 · (−5) = −25 ✓

Ответ: а) −2; г) 5

🔵 Уровень 2№ 4.307 (а, з)

Вычислите: а) −6,6 : 6; з) 11,55 : (−1,5).

  1. а) −(6,6 : 6) = −1,1
  2. з) −(11,55 : 1,5) = −7,7
  3. Проверка: −1,1 · 6 = −6,6; −7,7 · (−1,5) = 11,55 ✓

Ответ: а) −1,1; з) −7,7

🔵 Уровень 2№ 4.309 (а, б)

Найдите частное: а) −7/9 : 2/3; б) −3/13 : (−9/26).

  1. а) −7/9 · 3/2 = −(7 · 3)/(9 · 2) = −7/6 = −1 1/6
  2. б) 3/13 · 26/9 = (3 · 26)/(13 · 9) = 2/3
  3. Проверка: −1 1/6 · 2/3 = −7/6 · 2/3 = −14/18 = −7/9 ✓

Ответ: а) −1 1/6; б) 2/3

🟣 Уровень 3№ 4.312 (а, б)

Выполните действия: а) −6 · (−5) − (−40) : 8; б) 27 : (−27) − (−35) : 7.

  1. а) Сначала умножение и деление: 30 + 5 = 35
  2. б) −1 + 5 = 4
  3. Проверка порядка действий: деление и умножение всегда раньше сложения ✓

Ответ: а) 35; б) 4

🟣 Уровень 3№ 4.308 (г, д)

Выполните деление: г) −7 : (−2); д) −9 : 10.

  1. г) −7 : (−2) = 3,5 — оба минуса, результат положительный
  2. д) −9 : 10 = −0,9
  3. Проверка: 3,5 · (−2) = −7; −0,9 · 10 = −9 ✓

Ответ: г) 3,5; д) −0,9

🎓 Главное из урока

  • Знаки при делении — те же, что при умножении.
  • Разные знаки → частное отрицательное; одинаковые → положительное.
  • Делим модули, потом ставим знак.
  • Деление на дробь — умножение на перевёрнутую.
  • Частное проверяется умножением: частное · делитель = делимое.
  • На нуль делить нельзя.
  • Порядок действий: деление и умножение раньше сложения и вычитания.
