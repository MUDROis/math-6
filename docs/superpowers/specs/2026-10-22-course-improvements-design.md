# Дизайн: улучшение курса «Математика 6 класс» (2026-10-22)

## Интент и почему
Курс — 45 самодостаточных HTML-страниц (index + 44 урока). Пользователь (учитель/методист) просит: 1) настоящий набор формул вместо строчных записей, 3) печать форм, 6) интерактивные рисунки, 7) самопроверку с вводом ответа, 8) поиск и оглавление со scroll-spy.

## Цели
- Красивые вертикальные дроби, смешанные числа, степени во всех математических выражениях.
- Возможность распечатать урок без кнопок/интерактива.
- Ученик кликом ставит точку на координатной плоскости / числовой прямой и получает проверку.
- Ученик вводит ответ в поле у каждого задания и получает мгновенную обратную связь.
- Живой поиск по оглавлению курса; панель секций урока со scroll-spy.

## Не-цели / анти-цели
- Не вводить сервер/бэкенд (сайт открывается как локальные файлы).
- Не менять цветовую тему, шрифты и общую вёрстку (кроме добавления общих стилей).
- Не менять математическое содержание (только представление).
- Не трогать существующий HTML-контент сверх необходимого для фич.

## Ограничения
- Чистые статические файлы; без сборки, без пакетного менеджера.
- Библиотека формул — KaTeX через CDN (cdn.jsdelivr.net). Требует интернета при просмотре; офлайн-копий не делаем.
- Из 264 заданий ответы уже есть в блоках `.answer` — их используем как источник эталонных ответов.
- Валидация и «тесты» — Node-скрипты-проверки + визуальная проверка в браузере (browser.preview), т.к. это статический сайт без тест-раннера.

## Как реализуется (решения)
- Общий код выносится в `assets/course.css` и `assets/course.js`, подключается на всех страницах (вместо дублирования).
- `scripts/katex-convert.js` — однократная конвертация `<span class="math">` в LaTeX, обёртка `\(...\)`, рендер через KaTeX auto-render.
- `scripts/inject-input.js` — однократная инъекция поля ввода + кнопки проверки в каждый `.task` (с `data-answer` из эталонного ответа). Ответ в `course.js` финального ответа из блока `.answer` при разборе.
- Виджеты `NumberLineWidget` и `CoordinatePlaneWidget` — в `course.js`, встраиваются в уроки со статическими рисунками соответствующих типов.
- Поиск — на `index.html` по названиям/описаниям уроков (createElement, фильтрация `.lesson-row`).
- Сайдбар-оглавление — на страницах уроков: список `<h2>` + scroll-spy (IntersectionObserver).

## Что оставлено исполнителю
- Точное числовое наполнение упражнений виджетов (по учебному материалу каждого урока).
- Точная таблица правил конвертации (перечислена в плане).
- Выбор селекторов/детали реализации, не оговорённых выше.
