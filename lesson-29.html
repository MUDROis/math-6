Глава II • § 4, п. 29

П. 29. Сложение чисел с помощью координатной прямой

Прибавить — значит сдвинуть: вправо с плюсом, влево с минусом

Привет! Температура была 13°, а потом изменилась на −5° — стала 8°. Запишем: \(13 + (−5) = 8\). Прибавить число — значит переместить точку по координатной прямой. Сегодня учимся складывать любые числа с помощью стрелок.

Сложение перемещением

Прибавить к числу m число n — значит изменить число m на n единиц: при n > 0 точка сдвигается вправо, при n < 0 — влево.

Любое число от прибавления положительного числа увеличивается, а от прибавления отрицательного — уменьшается.

📌 Задача. Сложим числа −8 и 6 (пример из учебника).

  1. Ставим точку M(−8)
  2. Прибавляем 6 — перемещаемся на 6 единиц ВПРАВО
  3. Попадаем в N(−2): \((−8) + 6 = −2\) ✓

✅ Ответ: \(−2\)

Сумма противоположных чисел

Сумма двух противоположных чисел равна нулю: \(n + (−n) = 0\). От прибавления нуля число не изменяется: \(n + 0 = n\).

Например: \(9 + (−9) = 0\); \(10,5 + (−10,5) = 0\); \(−13 + 0 = −13\). Точка возвращается в начало отсчёта — «домой».

📌 Задача. Найдём с помощью прямой значение −6 + 4 + (−9) (упр. 4.150).

  1. Из −6 на 4 вправо → \(−2\)
  2. Из −2 на 9 влево → \(−11\)
  3. Проверка по группам: отрицательные −6 −9 = −15; 15 − 4? нет: −15 + 4 = −11 ✓

✅ Ответ: \(−11\)

Уравнения на прямой

Уравнение \(−5 + x = −1\) читается так: «из точки −5 куда нужно сдвинуться, чтобы попасть в −1?» Ответ: вправо на 4, значит \(x = 4\). Так координатная прямая помогает решать уравнения до изучения правил.

💡 Методическая подсказка № 29: Первое число — точка, второе — команда

Устройство. В сумме a + b число a — «где стоим», b — «куда идём»: плюс — вправо, минус — влево.

Правило-шаги. 1) Найди на прямой первое число. 2) Сдвинься на |b| в сторону знака b. 3) Читай координату, где остановился.

Проверь на контрасте: \(−2 + 5 = 3\) ✅ (вправо от −2). А пойти от −2 влево 🚫 — команда «+5» перепутана с «−5».

Мостик: в заданиях 1–3 рисуй стрелку для КАЖДОГО слагаемого по очереди.

Сложение стрелками

🖱 Потренируйся на числовой прямой

✍️ Проверь себя

Шесть заданий по нарастающей: два на прямой счёт (Уровень 1), два на комбинацию правил (Уровень 2) и два на смекалку (Уровень 3). Сначала реши сам — потом нажми «Проверить» и сверь каждый шаг.

🟢 Уровень 1№ 4.144 (а, б, г)

Используя координатную прямую, найдите сумму: а) −3 и 3; б) 5 и −7; г) 2 и −6.

  1. а) Из −3 на 3 вправо — попадаем в 0: \(−3 + 3 = 0\)
  2. б) Из 5 на 7 влево: \(5 − 7 = −2\)
  3. г) Из 2 на 6 влево: \(2 − 6 = −4\) ✓

Ответ: \(0; −2; −4\)

🟢 Уровень 1№ 4.145 (д, ж)

Сложите числа: д) 10,5 и −10,5; ж) 31/4 и −31/4.

  1. Слагаемые противоположные → сумма равна нулю
  2. \(10,5 + (−10,5) = 0\)
  3. \(3\frac{1}{4} + (−3\frac{1}{4}) = 0\). Проверка: точка возвращается в начало отсчёта ✓

Ответ: \(0; 0\)

🔵 Уровень 2№ 4.150 (д, е)

С помощью координатной прямой найдите значение выражения: д) \(−3 + 7 + (−8)\); е) \(1 + (−6) + 10\).

  1. д) −3 → на 7 вправо → 4 → на 8 влево → \(−4\)
  2. е) 1 → на 6 влево → −5 → на 10 вправо → \(5\)
  3. Проверка группами: д) −3−8 = −11, −11+7 = −4 ✓; е) 1+10 = 11, 11−6 = 5 ✓

Ответ: д) −4; е) 5

🔵 Уровень 2№ 4.149 (частично)

Какой станет температура, равная −13 °С, при изменении: на 4 °С; на −7 °С; на +15 °С?

  1. −13 + 4 = −9 °С
  2. −13 + (−7) = −20 °С
  3. −13 + 15 = 2 °С ✓

Ответ: −9 °С; −20 °С; 2 °С

🟣 Уровень 3№ 4.152 (а, г)

С помощью координатной прямой решите уравнение: а) \(−5 + x = −1\); г) \(x + 2 = −2\).

  1. а) Из −5 нужно попасть в −1: сдвиг вправо на 4 → \(x = 4\)
  2. г) Из x нужно попасть в −2 сдвигом на 2 вправо? нет: x + 2 = −2 значит от x сдвиг ВПРАВО на 2 → x левее −2 на 2 единицы
  3. \(x = −2 − 2 = −4\). Проверка: \(−4 + 2 = −2\) ✓

Ответ: а) x = 4; г) x = −4

🟣 Уровень 3№ 4.148

Точке N соответствует число n + (−6), а точке M — число n + 6. Найдите число, соответствующее середине отрезка MN.

  1. Точки N и M симметричны относительно точки с координатой n (сдвиги ±6)
  2. Середина симметричных точек — центр симметрии: \(n\)
  3. Проверка при n = 1: N(−5), M(7), середина \((−5 + 7) : 2 = 1\) ✓

Ответ: \(n\)

🎓 Главное из урока

  • Прибавить число — значит переместиться по координатной прямой.
  • Плюс — вправо, минус — влево.
  • От прибавления положительного числа число увеличивается, отрицательного — уменьшается.
  • Сумма противоположных чисел равна нулю: n + (−n) = 0.
  • Прибавление нуля не изменяет число.
  • Слагаемые обрабатывают по очереди — стрелка за стрелкой.
  • Уравнение a + x = b решается поиском сдвига от a к b.
