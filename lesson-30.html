Глава II • § 4, п. 30

П. 30. Сложение отрицательных чисел

Долг плюс долг — долг побольше: правило суммы отрицательных

Привет! Утром было −2°, за день похолодало ещё на 4°. К вечеру \(−2 + (−4) = −6^{\circ}\). Заметь: 6 — это сумма модулей 2 и 4, а знак — минус. Сегодня сформулируем правило сложения отрицательных чисел и научимся считать такие суммы быстро.

Правило сложения отрицательных чисел

Чтобы сложить два отрицательных числа, надо: 1) сложить их модули; 2) поставить перед результатом знак «−».

Например: \(−9,3 + (−4,8) = −(9,3 + 4,8) = −14,1\). Смысл прост: два долга складываются в один большой долг.

📌 Задача. Вычислим −46 + (−8) и −4 + (−127) (упр. 4.172).

  1. \(−46 + (−8) = −(46 + 8) = −54\)
  2. \(−4 + (−127) = −(4 + 127) = −131\)
  3. Проверка на прямой: из −46 двигаемся ещё на 8 влево → −54 ✓

✅ Ответ: −54 и −131

Дроби и десятичные

С дробями — то же правило: \(−\frac{7}{8} + (−\frac{1}{4}) = −(\frac{7}{8} + \frac{2}{8}) = −\frac{9}{8} = −1\frac{1}{8}\). С десятичными: \(−2,35 + (−9,65) = −12\). Главное — аккуратно привести дроби к общему знаменателю или выровнять запятые.

📌 Задача. Вычислим −4/5 + (−2/3).

  1. НОЗ (5, 3) = 15: \(−\frac{4}{5} = −\frac{12}{15}\), \(−\frac{2}{3} = −\frac{10}{15}\)
  2. Складываем модули: \(\frac{12}{15} + \frac{10}{15} = \frac{22}{15}\)
  3. Ставим минус: \(−\frac{22}{15} = −1\frac{7}{15}\) ✓

✅ Ответ: \(−1\frac{7}{15}\)

Удобные группировки

Свойства сложения позволяют складывать отрицательные числа «парами», дающими круглые суммы: \(−2,5 + (−0,87) + (−7,5) = (−2,5 + (−7,5)) + (−0,87) = −10 − 0,87 = −10,87\).

💡 Методическая подсказка № 30: Складывай модули, ставь минус

Устройство. Оба слагаемых «тянут влево» — итог ещё левее; сколько шагов — сумма модулей.

Правило-шаги. 1) Убери минусы — сложи числа. 2) Верни общий минус. 3) С дробями — сначала НОЗ, с десятичными — запятая под запятой.

Проверь на контрасте: \(−2,5 + (−7,5) = −10\) ✅. А сложить и забыть минус (\(10\)) 🚫 — самая частая ошибка.

Мостик: в заданиях 3 и 4 ищи пары, дающие круглую сумму, — группируй.

Шесть заданий по нарастающей: два на прямой счёт (Уровень 1), два на комбинацию правил (Уровень 2) и два на смекалку (Уровень 3). Сначала реши сам — потом нажми «Проверить» и сверь каждый шаг.

🟢 Уровень 1№ 4.172 (а, е)

Найдите сумму: а) \(−46 + (−8)\); е) \(−8 + (−37)\).

  1. \(−46 + (−8) = −(46 + 8) = −54\)
  2. \(−8 + (−37) = −(8 + 37) = −45\)
  3. Проверка: модули сложены, минус на месте ✓

Ответ: \(−54; −45\)

🟢 Уровень 1№ 4.176 (г, д)

Выполните сложение: г) \(−2,35 + (−9,65)\); д) \(−2,27 + (−0,73)\).

  1. \(−(2,35 + 9,65) = −12\)
  2. \(−(2,27 + 0,73) = −3\)
  3. Обе пары дают круглые суммы ✓

Ответ: \(−12; −3\)

🔵 Уровень 2№ 4.179 (б, в)

Найдите сумму: б) \(−\frac{7}{8} + (−\frac{1}{4})\); в) \(−\frac{4}{5} + (−\frac{2}{3})\).

  1. б) \(−(\frac{7}{8} + \frac{2}{8}) = −\frac{9}{8} = −1\frac{1}{8}\)
  2. в) НОЗ 15: \(−(\frac{12}{15} + \frac{10}{15}) = −\frac{22}{15} = −1\frac{7}{15}\)
  3. Проверка: обе суммы меньше −1 — верно, ведь слагаемые велики ✓

Ответ: б) −11/8; в) −17/15

🔵 Уровень 2№ 4.178 (а, б)

Вычислите удобным способом: а) \(−2,5 + (−0,87) + (−7,5)\); б) \(−4,7 + (−3,9) + (−1,1)\).

  1. а) Группируем: \((−2,5 + (−7,5)) + (−0,87) = −10 − 0,87 = −10,87\)
  2. б) \((−3,9 + (−1,1)) + (−4,7) = −5 − 4,7 = −9,7\)
  3. Проверка прямым счётом: а) 2,5 + 0,87 + 7,5 = 10,87 ✓; б) 4,7 + 3,9 + 1,1 = 9,7 ✓

Ответ: а) −10,87; б) −9,7

🟣 Уровень 3№ 4.173

Какой знак, < или >, надо поставить: а) \(−21 + (−15) ? −21\); б) \(−27 + (−41) ? −41\); в) \(−45 ? −5 + (−45)\); г) \(−1 ? −1 + (−13)\)?

  1. а) \(−21 + (−15) = −36 \lt −21\) → знак «<»
  2. б) \(−27 + (−41) = −68 \lt −41\) → «<»
  3. в) \(−5 + (−45) = −50\), а \(−45 \gt −50\) → «>»
  4. г) \(−1 + (−13) = −14\), а \(−1 \gt −14\) → «>» ✓

Ответ: а) <; б) <; в) >; г) >

🟣 Уровень 3№ 4.178 (г)

Вычислите удобным способом: \(−15,31 + (−25,48) + (−40,76) + (−14,69) + (−26,24) + (−27,52)\).

  1. Ищем «хвосты до круглого»: \(−15,31 + (−14,69) = −30\)
  2. \(−25,48 + (−26,24) = −51,72\); \(−40,76 + (−27,52) = −68,28\)
  3. \(−30 + (−51,72) + (−68,28) = −150\). Проверка: 51,72 + 68,28 = 120 ✓

Ответ: \(−150\)

🎓 Главное из урока

  • Сумма отрицательных чисел отрицательна.
  • Правило: сложить модули и поставить знак «−».
  • С дробями — сначала общий знаменатель, с десятичными — запятая под запятой.
  • Удобные группировки: пары, дающие круглые суммы.
  • Прибавление отрицательного числа уменьшает число.
  • Сравнение: сумма отрицательных меньше каждого слагаемого.
  • Проверка: забытый минус — первая ошибка в теме.
