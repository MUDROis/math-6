Глава II • § 4, п. 31

П. 31. Сложение чисел с разными знаками

Больший модуль побеждает: вычитай модули и бери его знак

Привет! Ночью было \(−7^{\circ}\), за утро потеплело на \(5^{\circ}\) — стало \(−2^{\circ}\). А если б потеплело на \(9^{\circ}\) — стало бы \(+2^{\circ}\). Кто «перевесит» — плюс или минус? Решает больший модуль. Сегодня — главное правило сложения чисел с разными знаками.

Правило сложения чисел с разными знаками

Чтобы сложить два числа с разными знаками, надо: 1) из большего модуля вычесть меньший; 2) поставить перед результатом знак того слагаемого, модуль которого больше.

Например: \(−7 + 5 = −(7 − 5) = −2\) — знак минус, ведь у −7 модуль больше. А \(−5 + 7 = +(7 − 5) = 2\) — знак плюс. Модули в обеих суммах одни и те же, но «победители» разные.

📌 Задача. Вычислим −4,5 + 7,8 и 0,5 + (−4,2) (упр. 4.204).

  1. \(−4,5 + 7,8 = +(7,8 − 4,5) = 3,3\) — больший модуль у 7,8
  2. \(0,5 + (−4,2) = −(4,2 − 0,5) = −3,7\)
  3. Проверка на прямой: из −4,5 шаг вправо на 7,8 приземляет в 3,3 ✓

✅ Ответ: 3,3 и −3,7

Дроби в сумме с разными знаками

С дробями порядок тот же: \(−\frac{4}{9} + \frac{2}{3} = −\frac{4}{9} + \frac{6}{9} = \frac{2}{9}\) — сначала к общему знаменателю, затем сравниваем модули. Смешанные числа: \(−1\frac{5}{8} + 3\frac{1}{4} = −1\frac{5}{8} + 3\frac{2}{8} = 1\frac{5}{8}\).

📌 Задача. Вычислим −4/9 + 2/3 (упр. 4.208).

  1. НОЗ (9, 3) = 9: \(\frac{2}{3} = \frac{6}{9}\)
  2. Модули: 4/9 < 6/9 → знак «+», вычитаем: \(\frac{6}{9} − \frac{4}{9} = \frac{2}{9}\)
  3. Проверка на прямой: из −4/9 шаг вправо на 6/9 — приземляемся в 2/9 ✓

✅ Ответ: \(\frac{2}{9}\)

Свойства сложения работают

В длинных суммах группируй удобные пары: \(5,3 + (−4,6 + 1,9) = 5,3 + (−2,7) = 2,6\). От перестановки слагаемых сумма не меняется — даже с минусами.

💡 Методическая подсказка № 31: Из большего модуля — меньший, знак победителя

Устройство. Плюс и минус «перетягивают канат»: чей модуль больше, тот и задаёт знак, а канат укоротился на разность модулей.

Правило-шаги. 1) Сравни модули. 2) Вычти из большего меньший. 3) Поставь знак «победителя».

Проверь на контрасте: \(−3 + 8 = 5\) ✅ (8 побеждает). А вычесть наоборот (\(3 − 8 = −5\)) 🚫 — знак взяли не у того слагаемого.

Мостик: в заданиях 1–4 первым делом сравнивай модули, потом вычитай.

Канат модулей

✍️ Проверь себя

Шесть заданий по нарастающей: два на прямой счёт (Уровень 1), два на комбинацию правил (Уровень 2) и два на смекалку (Уровень 3). Сначала реши сам — потом нажми «Проверить» и сверь каждый шаг.

🟢 Уровень 1№ 4.204 (а, г)

Выполните сложение: а) \(−4,5 + 7,8\); г) \(0,5 + (−4,2)\).

  1. а) \(7,8 \gt 4,5\) → знак «+»: \(7,8 − 4,5 = 3,3\)
  2. г) \(4,2 \gt 0,5\) → знак «−»: \(−(4,2 − 0,5) = −3,7\)
  3. Проверка на прямой ✓

Ответ: \(3,3; −3,7\)

🟢 Уровень 1№ 4.204 (е, з)

Выполните сложение: е) \(−2,2 + 1,8\); з) \(5,8 + (−6)\).

  1. е) \(−(2,2 − 1,8) = −0,4\)
  2. з) \(−(6 − 5,8) = −0,2\)
  3. Оба результата маленькие по модулю — слагаемые близки ✓

Ответ: \(−0,4; −0,2\)

🔵 Уровень 2№ 4.208 (в, д)

Найдите сумму: в) \(−\frac{4}{9} + \frac{2}{3}\); д) \(−1\frac{5}{8} + 3\frac{1}{4}\).

  1. в) \(\frac{2}{3} = \frac{6}{9}\) → \(−\frac{4}{9} + \frac{6}{9} = \frac{2}{9}\)
  2. д) \(3\frac{1}{4} = 3\frac{2}{8}\) → \(−1\frac{5}{8} + 3\frac{2}{8} = 1\frac{5}{8}\)
  3. Проверка в десятичных: д) −1,625 + 3,25 = 1,625 ✓

Ответ: в) 2/9; д) 15/8

🔵 Уровень 2№ 4.205 (б, в)

Составьте выражение и вычислите: б) к числу 5,3 прибавить сумму чисел −4,6 и 1,9; в) к сумме чисел −15 и −2,2 прибавить сумму чисел 7 и 3,8.

  1. б) \(5,3 + (−4,6 + 1,9) = 5,3 + (−2,7) = 2,6\)
  2. в) \((−15 + (−2,2)) + (7 + 3,8) = −17,2 + 10,8 = −6,4\)
  3. Проверка группами: в) −17,2 + 10,8: 17,2 − 10,8 = 6,4, знак «−» ✓

Ответ: б) 2,6; в) −6,4

🟣 Уровень 3№ 4.203 (б, г)

Решите уравнение: б) \(z + (−4) = −22\); г) \(p + (−24) = 4\).

  1. б) z — «откуда идти», чтобы после сдвига на 4 влево оказаться в −22: \(z = −22 + 4 = −18\)
  2. г) \(p = 4 + 24 = 28\)
  3. Проверка: \(−18 + (−4) = −22\) ✓; \(28 + (−24) = 4\) ✓

Ответ: б) z = −18; г) p = 28

🟣 Уровень 3№ 4.206

Какое из чисел 6; 18,9; −18,9; −12,9; −0,9 является корнем уравнения \(−3 + x = −21,9\)?

  1. Из уравнения \(x = −21,9 + 3 = −18,9\)
  2. Проверяем кандидатов: подходит \(−18,9\)
  3. Проверка подстановкой: \(−3 + (−18,9) = −21,9\) ✓ — остальные кандидаты не проходят

Ответ: \(x = −18,9\)

🎓 Главное из урока

  • Числа с разными знаками: вычитай из большего модуля меньший.
  • Знак суммы — знак слагаемого с большим модулем.
  • Если модули равны — сумма равна нулю.
  • Дроби сначала приводят к общему знаменателю.
  • В длинных суммах работают свойства сложения — группируй.
  • Уравнение a + x = b: x = b − a (через правило знаков).
  • Проверяй кандидатов в корни подстановкой.
